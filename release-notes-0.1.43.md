# Vulgar Notes 0.1.43

- Set the document body font, math font and point sizes from **Document tools → Document typography**. Select New Computer Modern or STIX Two Math for equations, and choose a fixed point size or let equations follow the surrounding text. Local text sizes also use points. Existing pixel-sized text keeps its original size.
- Toggle formatting marks to see spaces, tabs, line breaks and paragraph ends while editing.
- Export a PDF directly on Windows, or use the print dialog on the web. Choose the paper, orientation, margins and page numbers. Equations are typeset at the printable width, figures stay with their captions where space permits, and long tables can repeat their headers.
- HTML and PDF exports preserve text and math sizing. Exported HTML loads the selected math font when MathJax re-typesets equations.
- The standalone formula editor includes optional input panels, explicit LaTeX import, and read-only LaTeX and syntax tree views.
- The prose editor has a simpler toolbar. Paragraph drag handles have been removed. Mouse users on touchscreen computers can select a paragraph and operate on it from its context menu.

## Windows downloads

Choose the portable executable to run without installing, or the setup executable to install the app and register the .vulgar file association. SHA256SUMS.txt contains checksums for both downloads.
