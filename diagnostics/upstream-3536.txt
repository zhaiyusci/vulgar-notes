it took a little effort, but I had worked out the changes needed to support the `\sym` and `\math` commands more in line with the `unicode-math` package in actual LaTeX (or rather `lualatex` and `xelatex`), along with the handling of literal Math Alphanumerics characters.  I also added the missing `literal` setting for `math-style`, and corrected the capitalization of `french` to be consistent with `unicode-math`.  But I didn't get the chance to write it up before other things took over my time.  

I have gotten back to it finally, and present you a configuration that implements the changes, in case you wanted to use it.  It is pretty big, as there are changes to a number of places.  

There are two new configuration options `tex.mathStyleGreekLC`, which determines whether `\mathrm`, `\mathit`, and the other `\math` macros from the original `ams` distribution will modify the lower-case Greek letters or not (original behavior is `false`, but `unicode-math` behavior is `true`), and `mathStyleMathAlphabets`, which determines whether MathJax will modify the characters in the Unicode Math Alphanumerics block or not.  The default for both is `false`, so the behavior will be to modify the usual Latin and Greek blocks, but leave the Math Alphanumerics alone (I think that was what you preferred above).

I also added `symbbit` and `\mathbbit`, as you pointed out they were missing.  The STIX2 font has italic double-struck characters, so these macros work with that font, at least, but that is the only one currently.

Here is the (extensive) configuration in an example file that illustrates the various macros and raw unicode characters.  You can set the `math-style` and other values at the top.  I've turned off speech generation just to speed up the display, as big tables like this will lots of entries take it a while.
